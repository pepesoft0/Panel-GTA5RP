## 📖 Описание

**GTA 5 RP Bot** — программа, которая автоматизирует рутину в GTA 5 RP: от колеса удачи и лотереи до работ, мини-игр и крафта. Запускаете нужный режим — бот делает всё сам, а управлять им можно удалённо через Telegram.

### ✨ Возможности

#### 🎰 Бонусы и активности
- 🎡 **Колесо удачи** — автоматическая прокрутка каждые 4 часа
- 🎟️ **Лотерея** — автоматическая покупка лотерейного билета за 1500$ каждые 2 часа
- 🏋️ **Качалка** — автоматическая прокачка силы *(требуется предварительная покупка билета)*

#### 🔫 Автолут
- 🎒 Мгновенный сбор оружия с пола без необходимости нажимать клавишу `E`

#### 💤 Анти-АФК
- ⏳ 2 режима работы: **безопасный режим** и **режим для выполнения контрактов**

#### 🧵 Мини-игры и крафт
- ✂️ Автоматическое прохождение **швейки**
- 🌿 Скрутка **косяков**
- 📜 Крафт **схем**
- ⚠️ Требуется **EN раскладка**

#### ⛏️ Работы
- 🐄 **Ферма** — доение коров
- 🧱 **Стройка**
- ⛏️ **Шахта**
- 📦 **Порт** — прохождение мини-игры
- ⚡ **Электрик** — мини-игра на диагностике сети
- ⚡ **Электрик ур.2** — мини-игра на диагностике сети
- 🔧 **Механик** — мини-игра починки машины 🚗🛠️

#### 🚨 Деморган
- Режимы **«Рубашки»**, **«Станок»** и **«АФК-Деморган»**
- 💬 В режиме АФК-Деморган, пока вы стоите в АФК, софт сам отвечает на вопросы, которые выбрасывает сервер; персонаж при этом сам не бегает

#### 🍳 Кулинария и выживание
- 🍕 **Кулинария** — автоматический крафт любой еды
- 🍔 **Анти-голод** — авто-прожим еды из инвентаря по заданному таймеру ⏱️

#### 🔄 АвтоРелог
- 🚪 Автоматический перезаход на сервер: обычный полный перезапуск игры или быстрый релог через `F1`

#### 📲 Telegram-управление
- 🎛 Удалённый контроль функций через ТГ-бота
- 📸 Отправка скриншота игры по команде
- 🔌 Авто-переподключение к серверу

#### 🎯 Дополнительный функционал
- 🏃 **Автобег** — персонаж сам не бежит, направлением нужно управлять мышью самостоятельно
- 🎯 **Кастомный прицел** по центру экрана с выбором цвета
- 🎡 **Обновлённый интерфейс рулетки**

### 🚀 Быстрый старт
